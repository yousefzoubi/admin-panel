# Admin Panel Frontend

واجهة Admin Panel متجاوبة وجاهزة للربط مع مشروع الـ backend الموجود في `Admin-Panel-Project.zip`.
التصميم مبني على Glassmorphism مع دعم العربية والإنجليزية وDark Mode وSocket.IO Chat.

## التشغيل

1. شغّل الـ backend الأصلي أولًا من مجلده:

```bash
npx tsx src/index.js
```

إذا لم تكن الحزم مثبتة، شغّل `npm install` مرة واحدة داخل مجلد الـ backend. اترك ملف `.env` والـ backend كما هما، وتأكد أن PostgreSQL يعمل وأن قاعدة البيانات الموجودة في `.env` متاحة.

2. فك ضغط هذا المجلد في أي مكان.
3. افتح Terminal داخل مجلد الواجهة، ثم شغّل:

```bash
npm run dev
```

4. افتح الرابط الظاهر، غالبًا: `http://localhost:5173`.

يجب أن يعمل الـ backend في نافذة أخرى على `http://localhost:9999`. الواجهة تعمل كوسيط محلي للطلبات، لذلك لا تحتاج إلى تعديل `cors` في الباك، ولا تحتاج الواجهة إلى `npm install` لأنها تستخدم Node فقط.

## إذا كان الباك على منفذ مختلف

انسخ `.env.example` إلى `.env` وعدّل:

```env
BACKEND_URL=http://localhost:9999
PORT=5173
```

## الوظائف الموجودة

- تسجيل الدخول وإنشاء حساب.
- تجديد الـ access token تلقائيًا باستخدام refresh token.
- لوحة ملخص وإحصائيات.
- إضافة وتعديل وحذف المقالات المملوكة للمستخدم.
- إدارة المستخدمين والأدوار للـ Admin.
- عرض سجل العمليات للـ Admin.
- تصميم متجاوب مع الهاتف.
- تبديل لغة الواجهة بين العربية والإنجليزية من زر `EN / عربي`.
- عرض محتوى المقال بالعربية أو الإنجليزية حسب اللغة المختارة.
- Dark Mode محفوظ تلقائيًا في المتصفح.
- Chat يعمل عبر Socket.IO عند توفره، ويعود تلقائيًا إلى HTTP إذا لم يتم تحميل عميل Socket.IO.

لم يتم تعديل أي ملف من ملفات الـ backend.

## ملاحظة عن الأدوار

الواجهة تعرض `MODERATOR` ضمن الأدوار لأن الـ schema والـ authorization في الباكند يدعمانه.
لكن في نسخة الباكند المرسلة، `validateUpdateUser` قد يمنع تعيين هذا الدور من شاشة تعديل المستخدم إذا كانت قائمة الأدوار المسموحة لا تحتوي `MODERATOR`. هذا سلوك من الباكند وليس من الواجهة، ولم أعدّل الباكند حسب طلبك.
